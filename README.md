# ⚙️ ServiceFlow

Sistema Full Stack.

O objetivo do sistema é centralizar o gerenciamento de clientes, funcionários, chamados e ordens de serviço através de uma interface web integrada a uma API REST desenvolvida com Spring Boot.

---

## 🚀 Demonstração

🌐 **Aplicação:**  
https://service-flow-n9wv.vercel.app/login.html

💻 **Back-end:**  
Java + Spring Boot

## ✨ Funcionalidades

- Login com autenticação JWT
- Controle de acesso por perfil
- Dashboard administrativo
- Gestão de Clientes
- Gestão de Funcionários
- Aprovação de Funcionários
- Gestão de Chamados
- Gestão de Ordens de Serviço
- Atualização de Perfil
- Alteração de Senha
- Paginação e filtros
- Validações de dados
